# Introduction to R: CPP Lab Cohort 2026

Teaching materials for a four-week introductory R training held at the CPP Lab, Department of Crop Production and Protection.

**Instructor:** Haruna Isola Aremu
**Schedule:** Mondays and Wednesdays, 2:00 to 4:00 pm
**Dates:** 16 November to 9 December 2026

## Who this is for

Beginners with no prior R experience. Basic familiarity with spreadsheets is helpful.

## Requirements

- A laptop with R and RStudio installed (see the setup guide below)
- Packages: `tidyverse`, `readxl`, `janitor`

## Setup

1. Install R from https://cran.r-project.org
2. Install RStudio Desktop from https://posit.co/download/rstudio-desktop
3. In RStudio, run:

```r
install.packages(c("tidyverse", "readxl", "janitor"))
```

## Course outline

| Session | Week | Topic |
|---|---|---|
| 1 | 1 | Getting started with R and RStudio |
| 2 | 1 | Data types and importing data |
| 3 | 2 | Core dplyr verbs |
| 4 | 2 | Summaries, reshaping, and missing values |
| 5 | 3 | Plotting with ggplot2 |
| 6 | 3 | Descriptive and basic inferential statistics |
| 7 | 4 | Analysing a field trial |
| 8 | 4 | Applied mini-project and wrap-up |
