# Week 1, Session 1: Objectives

By the end of this session, participants will be able to:

- Identify the main panes and tabs in RStudio (Source, Console, Environment, History, Files, Plots, Packages, Help, and Viewer) and state what each one is used for

- Write comments to explain their code, and create section headers to organise a script

- Use R as a calculator to perform basic arithmetic and common calculations

- Create, overwrite, and manipulate R objects

- Apply the basic rules for naming R objects

- Call R functions using the correct syntax, including named arguments

- Nest multiple functions in a single line of code
