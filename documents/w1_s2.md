# Week 1, Session 2: Objectives

By the end of this session, participants will be able to:

1.  Create an R project and explain why projects keep work organised
2.  Create vectors of numbers, text, and categories
3.  Create factors and lists, and explain when each one is used
4.  Combine vectors to build a data frame
5.  Explain the difference between a data frame and a tibble
6.  Import CSV and Excel files using `read_csv()` (readr) and `read_excel()` (readxl)
7.  Inspect a dataset using `str()`, `head()`, and `summary()`
